## CS-001 LVS 与 Web 服务器

**题目：**

从以下四个选项选出不同的一个。

**选项：**

- A. LVS
- B. Nginx
- C. Lighttpd
- D. Apache

**正确答案：** A

**你的答案：** C

**解析：**

Nginx、Lighttpd、Apache 都是常见的 Web 服务器，可以直接处理 HTTP 请求并返回 Web 内容。

LVS 是 Linux Virtual Server 的缩写，主要用于构建 Linux 虚拟服务器集群，常见角色是四层负载均衡。它更偏向负载均衡/集群调度系统，不是传统意义上的 Web 服务器。

**考点：**

- LVS：Linux Virtual Server，常用于负载均衡
- Nginx、Lighttpd、Apache：Web 服务器

**易错点：**

- Nginx 既可以做 Web 服务器，也可以做反向代理和负载均衡
- 但本题找不同，LVS 与另外三者类别不同
