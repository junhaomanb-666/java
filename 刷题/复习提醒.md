## day1 优先复习清单

- SQL 逻辑执行顺序
- MySQL 视图作用与可更新性
- MySQL 字段别名写法
- Java 7 `ConcurrentHashMap` 分段锁
- `Arrays.asList()` 固定长度列表
- NIO `Channel`、`Buffer`、非阻塞
- `do-while` 条件含义
- 继承传递性与向上转型
- `byte`、`short`、`char` 运算自动提升为 `int`

## day2 优先复习清单

- 字符串常量池
- 编译期字符串拼接与运行期字符串拼接
- `new String()` 对引用比较的影响
- 字符串内容比较用 `equals()`，不要用 `==`
- 装箱：基本类型到包装类
- 拆箱：包装类到基本类型
- LVS 与 Web 服务器的区别

## day3 优先复习清单

- `ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)`
- `ROUND()` 与 `TRUNCATE()` 的区别
- 共享锁、更新锁、排他锁、架构锁
- `INSERT INTO` 的正确语法
- 聚合函数不能直接放在 `WHERE` 中比较
- `UPDATE` 的 `SET` 和 `WHERE` 都可以使用子查询
- 方法重载看参数列表，不看返回值
- 向下转型可能抛出 `ClassCastException`
- `short` 运算会提升为 `int`
- 子类构造方法必须先调用父类构造方法

## day4 优先复习清单

- 左连接结果行数可能大于左表
- 当月查询用 `DATE_FORMAT(create_time, '%Y%m')`
- `UNION ALL` 合并统计结果
- 多重 `catch` 先子类后父类
- `StringBuffer` 线程安全，`StringBuilder` 非线程安全
- `start()` 启动线程，`run()` 是线程执行入口
- `static` 方法中不能使用 `this`
- `Object` 有 `finalize()`，没有 `finally()`
- 字符串变量拼接通常运行期创建对象
- 数组复制效率优先记 `System.arraycopy`
- `Collection` 是接口，`Collections` 是工具类
- `volatile` 保证可见性和有序性，不保证原子性

## day6 优先复习清单

- `A a = new A()`：栈中引用，堆中对象
- `--y` 先减再用，`y--` 先用再减
- 静态内部类不能直接访问外部类非静态成员
- `PreparedStatement` 中一个 `?` 只能绑定一个值
- Java 方法必须定义在类中，没有全局函数
- 添加列时必须指定字段类型
- 列级权限应授予具体列的 `SELECT` 权限
- MySQL 模拟 `FULL JOIN`：`INNER JOIN + LEFT JOIN 未匹配 + RIGHT JOIN 未匹配`

## day8 优先复习清单

- `SELECT INTO` 创建新表，`INSERT INTO SELECT` 插入已有表
- SQL Server 自动提交下单条语句不是“显性事务”
- 抽象方法不能有方法体，普通方法没有 `abstract` 必须有方法体
- 非静态内部类创建：`new Outer().new Inner()`
- Bootstrap、Extension、System/Application ClassLoader
- `finally` 中的 `return` 会覆盖前面返回值

## day9 优先复习清单

- 唯一索引：`CREATE UNIQUE INDEX name ON table(col)`
- `READ COMMITTED` 只能读已提交版本，避免脏读
- 成员变量有默认值，局部变量没有默认值
- 默认访问权限：同包可访问，包外不可访问
- `request` 读请求，`response` 写响应
- 浮点字面量默认是 `double`
- Java 体系结构：语言、`.class` 文件格式、API、JVM
