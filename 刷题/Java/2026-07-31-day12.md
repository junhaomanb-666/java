## 题目 1：Java 参数传递与数组引用

下面 Java 代码的运行结果为？

```java
public class Test {
    public static void main(String[] args) {
        int[] da1 = new int[]{1, 3, 5};
        int[] da2 = new int[]{2, 4, 6};
        System.out.print(da2[da1[0]]);
        interchange(da1, da2);
        System.out.print(da1[da2[0]]);
    }

    static void interchange(int[] da1, int[] da2) {
        int[] dat = da1;
        da1 = da2;
        da2 = dat;
    }
}
```

A. 45  
B. 54  
C. 抛出 `ArrayIndexOutOfBoundsException`  
D. 43

正确答案：A

原解析：

Java 参数传递是值传递。这里传递的是两个数组引用的副本，所以方法结束后，`main` 中的 `da1` 和 `da2` 并没有交换。

补充解析：

第一段输出 `da2[da1[0]]`，因为 `da1[0] = 1`，所以输出 `da2[1] = 4`。调用 `interchange(da1, da2)` 时，传进去的是引用值的副本，方法内部只是交换形参副本，不会改变 `main` 中的 `da1` 和 `da2`。第二段输出 `da1[da2[0]]`，因为 `da2[0] = 2`，所以输出 `da1[2] = 5`。最终结果为 `45`。

记忆点：Java 只有值传递。对象、数组作为参数时，传的是“引用值的副本”。

## 题目 2：static 变量访问与共享

关于以下程序代码的说明正确的是？

```java
class HasStatic {
    private static int x = 100;

    public static void main(String args[]) {
        HasStatic hs1 = new HasStatic();
        hs1.x++;
        HasStatic hs2 = new HasStatic();
        hs2.x++;
        hs1 = new HasStatic();
        hs1.x++;
        HasStatic.x--;
        System.out.println("x=" + x);
    }
}
```

A. 第 5 行不能通过编译，因为引用了私有静态变量  
B. 第 10 行不能通过编译，因为 `x` 是私有静态变量  
C. 程序通过编译，输出结果为 `x=103`  
D. 程序通过编译，输出结果为 `x=102`

正确答案：D

原解析：

`x` 是 `static` 静态变量，属于整个 `HasStatic` 类，所有对象共享同一个 `x`，并且代码就在 `HasStatic` 类内部，可以访问 `x`。

补充解析：

`private` 只限制类外访问，在 `HasStatic` 类内部可以访问这个私有静态变量。变化过程：初始 `x = 100`，`hs1.x++` 后为 101，`hs2.x++` 后为 102，重新给 `hs1` 赋新对象不影响静态变量，`hs1.x++` 后为 103，`HasStatic.x--` 后为 102，所以输出 `x=102`。

记忆点：静态变量属于类，被所有对象共享；推荐用 `类名.静态变量` 访问。

## 题目 3：引用比较、赋值与自动装箱

根据下面的程序代码，哪些选项的值返回 `true`？

```java
public class Square {
    long width;

    public Square(long l) {
        width = l;
    }

    public static void main(String arg[]) {
        Square a, b, c;
        a = new Square(42L);
        b = new Square(42L);
        c = b;
        Long s = 42L;
    }
}
```

A. `a == b`  
B. `s == a`  
C. `b == c`  
D. `a.equals(s)`

正确答案：C

原解析：

`s` 会自动装箱成 `Long` 对象。

解析图：

![内存解析](../解析图片/day12/485624_1428569659849_neicun.png)

补充解析：

`a = new Square(42L)` 创建一个新的 `Square` 对象；`b = new Square(42L)` 又创建另一个新的 `Square` 对象；`c = b` 表示 `c` 和 `b` 指向同一个对象；`Long s = 42L` 中，`42L` 自动装箱为 `Long` 对象。

逐项判断：`a == b` 比较引用地址，两个不同对象，为 `false`；`s == a` 中 `Long` 和 `Square` 类型不兼容；`b == c` 指向同一个对象，为 `true`；`a.equals(s)` 中 `Square` 没有重写 `equals()`，默认比较对象地址，也为 `false`。

记忆点：`==` 比较引用变量时，比较的是是否指向同一个对象。

## 题目 4：继承、多态与父类引用

对于如下代码，描述正确的是？

```java
class Animal {
    public void move() {
        System.out.println("the animal is moving");
    }
}

class Dog extends Animal {
    public void move() {
        System.out.println("the dog can run");
    }

    public void bark() {
        System.out.println("the dog can bark");
    }
}

public class TestDog {
    public static void main(String args[]) {
        Animal a = new Animal();
        Animal b = new Dog();
    }
}
```

A. `a` 对象可以调用 `move` 方法，输出为：`the dog can run`  
B. `a` 对象可以调用 `move` 方法，输出为：`the animal is moving`  
C. `b` 对象可以调用 `bark` 方法，输出为：`the dog can bark`  
D. `b` 对象不能调用 `bark` 方法

正确答案：B、D  
你的答案：B、C

原解析：

由于 Java 有父类委托机制。父类委托机制工作过程是：如果一个类加载器收到了类加载的请求，它首先不会自己去尝试加载这个类，而是把这个请求委托给父类加载器去完成，每一个层级的类加载都是如此，因此所有的加载请求最终都应该传送到顶层的启动类加载器中，只有当父加载器反馈自己无法完成这个加载请求时，子加载器才会尝试自己去加载。`b` 此时是一个 `Animal` 对象，`Animal` 对象没有 `bark` 方法，因此 `b` 对象不能调用 `bark` 方法。

补充解析：

这题真正考的是继承、多态和编译期类型，不是类加载器的双亲委派。

```java
Animal a = new Animal();
Animal b = new Dog();
```

`a` 的编译期类型和运行期类型都是 `Animal`，所以 `a.move()` 调用 `Animal` 的 `move()`，输出 `the animal is moving`。`b` 的编译期类型是 `Animal`，运行期类型是 `Dog`。如果调用被重写的 `move()`，会动态绑定到 `Dog.move()`。但是 `bark()` 是 `Dog` 特有方法，`Animal` 类型里没有这个方法，所以 `b.bark()` 在编译期就过不去。

如果想调用 `bark()`，需要先向下转型：

```java
((Dog) b).bark();
```

记忆点：能不能调用某方法，先看引用变量的编译期类型；调用哪个重写方法，再看对象的运行期类型。

## 题目 5：静态方法访问实例变量

类 `GodSon` 的代码如下：

```java
public class GodSon {
    private int number = 0;

    public static int getSonCount() {
        return number;
    }

    public GodSon() {
        number++;
    }
}
```

类 `GodWife` 的代码如下：

```java
for (int i = 0; i < new int[5]; i++) {
    GodSon god = new GodSon();
}
System.out.println(GodSon.getSonCount());
```

请问编译运行的结果是什么？

A. 类 `GodSon` 编译失败  
B. 第 28 行代码输出值是 3  
C. 第 28 行代码输出值是 1  
D. 第 26 行代码在运行时会产生错误

正确答案：A

原解析：

静态方法里不能调用实例变量。

补充解析：

`number` 是实例变量，属于某个具体的 `GodSon` 对象；`getSonCount()` 是静态方法，属于类本身。静态方法执行时不依赖具体对象，所以不能直接访问实例变量：

```java
public static int getSonCount() {
    return number; // 编译错误
}
```

如果题目想统计创建了多少个 `GodSon` 对象，`number` 应该写成静态变量：

```java
private static int number = 0;
```

另外，题目中的循环条件如果真实写成 `i < new int[5]`，也是类型不匹配；通常应写成 `i < new int[5].length` 或 `i < 5`。但本题选项给出的核心考点是 `GodSon` 类中静态方法访问实例变量导致编译失败。

记忆点：静态方法不能直接访问非静态成员；非静态成员必须依附具体对象。
