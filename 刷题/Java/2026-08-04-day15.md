## 题目 1：形式参数

Java 中，下列说法正确的是？

A. 形式参数可被字段修饰符修饰  
B. 形式参数不可以是对象  
C. 形式参数为方法被调用时真正被传递的参数  
D. 形式参数被视为 `local variable`

正确答案：D  
你的答案：B

原解析：

A. 形式参数只能使用 `final` 修饰符，用于限制参数在方法内被修改。

B. 形式参数可以是对象类型，如 `String`、自定义类等。

```java
public void printMessage(String message) {
    // ...
}
```

C. Java 采用值传递，实际传递的是实参的副本。基本类型传递值，引用类型传递引用地址的副本，而非形参本身。

D. 形式参数在方法内部的作用域与局部变量相同，仅在方法体内有效，且需在方法调用时初始化。

```java
public void greet(String name) {
    System.out.println(name);
}
```

补充解析：

形参就是方法声明中的参数变量，本质上可以看作方法内部的局部变量。它的生命周期和作用域都局限在方法调用期间、方法体内部。

记忆点：形参属于局部变量；Java 参数传递永远是值传递。

## 题目 2：方法调用完成后的内存释放

在 Java 中，对于不再使用的内存资源，如调用完成的方法，“垃圾回收器”会自动将其释放。

A. 正确  
B. 错误

正确答案：B  
你的答案：A

原解析：

方法调用时，会创建栈帧在栈中；调用完成后由程序自动出栈释放，而不是由 GC 释放。

JVM 内存可简单分为三个区：

1. 堆区：用于存放所有对象，是线程共享的，数组也属于对象。
2. 栈区：用于存放基本数据类型的数据和对象的引用，是线程私有的，分为虚拟机栈和本地方法栈。
3. 方法区：用于存放类信息、常量、静态变量、编译后的字节码等，是线程共享的，也被称为非堆。

Java 的垃圾回收器主要针对堆区。

补充解析：

方法调用完成后，方法对应的栈帧会随着方法返回自动弹出，里面的局部变量、操作数栈等也随之释放。GC 主要负责回收堆中不再被引用的对象，而不是回收“已经调用完成的方法”。

记忆点：方法调用进栈，方法结束出栈；GC 主要管堆对象。

## 题目 3：`sleep` 和 `wait`

关于 `sleep` 和 `wait`，以下描述错误的是？

A. `sleep` 是线程类的方法，`wait` 是 `Object` 的方法。  
B. `sleep` 不释放对象锁，`wait` 放弃对象锁。  
C. `sleep` 暂停线程，但监控状态依然保持，结束后会自动恢复。  
D. `wait` 进入等待锁定池，只有针对该对象发出 `notify` 方法获得对象锁进入运行状态。

正确答案：D  
你的答案：B

原解析：

D. 线程调用 `wait()` 后进入等待集合。其他线程调用 `lock.notify()` 只会唤醒一个等待线程，但被唤醒的线程不会立即运行，也不会立即获得对象锁。它要等调用 `notify()` 的线程退出同步代码块、释放锁，然后再竞争锁，获得锁后才能继续执行。

线程还可能因为以下原因结束等待：

- `notifyAll()`
- `wait(timeout)` 超时
- 被中断
- 极少数情况下虚假唤醒

所以 D 中“只有 `notify`，并且直接获得锁进入运行状态”的描述错误。

C 基本正确。`sleep()` 会让当前线程暂停指定时间，但不会释放锁。休眠时间结束后，线程进入可运行状态，等待 CPU 调度，并不是保证立即开始执行。所以“自动恢复”更严谨地说是：休眠结束后自动具备继续运行的资格。

A 正确。因为任何对象都可以作为锁，所以 `wait()`、`notify()`、`notifyAll()` 定义在 `Object` 中。

补充解析：

`sleep()` 和锁没有直接绑定关系，只是让当前线程暂停一段时间；`wait()` 必须在同步代码块或同步方法中调用，并且调用后会释放当前对象锁。

记忆点：

- `sleep()`：线程睡眠，不释放锁。
- `wait()`：对象等待，释放锁，醒来后还要重新竞争锁。
- `notify()`：只负责唤醒等待线程，不负责立刻把锁交给它。

## 题目 4：正则表达式非数字字符

正则表达式中，表示匹配非数字字符的字符是？

A. `\b`  
B. `\d`  
C. `\B`  
D. `\D`

正确答案：D  
你的答案：A

原解析：

`\D` 表示匹配非数字字符。

补充解析：

常见正则简写：

- `\d`：匹配数字，等价于 `[0-9]`。
- `\D`：匹配非数字，等价于 `[^0-9]`。
- `\b`：单词边界。
- `\B`：非单词边界。

记忆点：小写 `d` 是 digit 数字；大写 `D` 是 non-digit 非数字。
