## 题目 1：接口定义

以下哪个接口的定义是正确的？

A. `interface B { void print() { } ; }`  
B. `interface B { static void print(); }`  
C. `// A1、A2 为已定义的接口 abstract interface B extends A1, A2 { abstract void print() { } ; }`  
D. `interface B { void print(); }`

正确答案：D

原解析：

A 应该没有大括号；B 接口中的方法可以被 `default` 和 `static` 修饰，但是被修饰的方法必须有方法体；C 接口可以多继承，错在抽象方法不能有方法体。

补充解析：

接口中的普通方法默认是 `public abstract`，抽象方法只有方法声明，不能写方法体。因此：

```java
interface B {
    void print();
}
```

是合法写法。

逐项看：

- A：`void print() {}` 是方法体，接口普通抽象方法不能有方法体。
- B：`static` 方法可以出现在接口中，但必须有方法体。
- C：接口可以 `extends` 多个接口，但 `abstract void print() {}` 仍然错在抽象方法有方法体。
- D：合法。

记忆点：接口抽象方法无方法体；接口 `default/static` 方法必须有方法体。

## 题目 2：枚举 enum

下列哪个选项描述了 Java 中的枚举 `enum`？

A. 枚举可以包含实例方法和实例变量  
B. 枚举可以与其他类继承  
C. 枚举可以作为一种数据类型  
D. 枚举不能包含构造函数

正确答案：A、C

原解析：

B 枚举隐式继承自 `java.lang.Enum` 类，且 Java 不支持多继承，因此枚举不能被其他类继承，也不能继承其他类；D 枚举可以包含构造函数，但必须为私有，默认隐式私有。

Java 不支持多继承：一个 Java 类不能同时继承两个或多个父类。

补充解析：

枚举本质上是一种特殊的类，可以定义字段、方法、构造方法，也可以作为类型使用：

```java
enum Season {
    SPRING("春天"), SUMMER("夏天");

    private final String desc;

    Season(String desc) {
        this.desc = desc;
    }

    public String getDesc() {
        return desc;
    }
}
```

但枚举已经默认继承 `java.lang.Enum`，不能再继承其他类；枚举构造方法不能是 `public`，通常省略修饰符或写成 `private`。

记忆点：枚举是类型，也是一种特殊类；能有属性、方法、私有构造器，不能继承其他类。

## 题目 3：二维数组声明

下面哪个语句是创建数组的正确语句？

A. `float f[][] = new float[6][6];`  
B. `float []f[] = new float[6][6];`  
C. `float f[][] = new float[][6];`  
D. `float [][]f = new float[6][6];`  
E. `float [][]f = new float[6][];`

正确答案：A、B、D、E  
你的答案：A、D、E

原解析：

数组命名时名称与 `[]` 可以随意排列，但声明的二维数组中第一个中括号中必须要有值，它代表的是在该二维数组中有多少个一维数组。

补充解析：

Java 数组声明时，`[]` 可以放在类型后，也可以放在变量名前后，所以这些声明都合法：

```java
float f[][];
float[] f[];
float[][] f;
```

创建二维数组时，第一维长度必须明确：

```java
new float[6][6]; // 合法
new float[6][];  // 合法，先创建 6 个一维数组引用
new float[][6];  // 不合法，第一维缺失
```

所以 B 也是正确的，你这题漏选了 B。

记忆点：二维数组可以只指定第一维，不能只指定第二维。

## 题目 4：ExecutorService 关闭

下列有关 `ExecutorService` 的关闭的说法中，正确的是？

A. 调用 `shutdown` 方法后，`ExecutorService` 会拒绝新的请求，并继续执行现有任务。  
B. `shutdown` 方法是一个阻塞方法，会一直阻塞直到线程池关闭。  
C. `shutdownNow` 方法会返回尚未开始执行的任务。  
D. `awaitTermination` 是一个阻塞方法，会阻塞直到线程池关闭，或者超时。

正确答案：A、C、D  
你的答案：B、C

原解析：

B 它只是发出“有序关闭”的通知，然后通常很快返回。线程池里的已有任务可能仍在后台运行。

补充解析：

`ExecutorService` 关闭相关方法要分清：

- `shutdown()`：有序关闭。不再接收新任务，但已提交任务会继续执行；它不是阻塞等待方法。
- `shutdownNow()`：尝试停止正在执行的任务，并返回还没有开始执行的任务列表。
- `awaitTermination(timeout, unit)`：阻塞等待线程池终止，直到线程池关闭、超时或当前线程被中断。

记忆点：`shutdown()` 只是发通知；真正等待用 `awaitTermination()`。

## 题目 5：ThreadLocal

关于 `ThreadLocal` 类，以下说法正确的是？

A. `ThreadLocal` 继承自 `Thread`  
B. `ThreadLocal` 实现了 `Runnable` 接口  
C. `ThreadLocal` 重要作用在于多线程间的数据共享  
D. `ThreadLocal` 是采用哈希表的方式来为每个线程都提供一个变量的副本  
E. `ThreadLocal` 保证各个线程间数据安全，每个线程的数据不会被另外线程访问和破坏

正确答案：D、E  
你的答案：A、B、E

原解析：

A 它们是两个不同的类：`Thread` 表示线程；`ThreadLocal` 保存线程自己的局部数据。

B `ThreadLocal` 并没有实现 `Runnable` 接口，它与线程的执行方式无关，只负责提供线程本地变量的存储机制。

C `synchronized` 用于线程间的数据共享，而 `ThreadLocal` 则用于线程间的数据隔离。

D 每个 `Thread` 对象内部都有自己的 `ThreadLocalMap`，它类似一个专门的哈希表：

```text
Thread
  └── ThreadLocalMap
        ├── ThreadLocal对象1 → 当前线程的数据1
        └── ThreadLocal对象2 → 当前线程的数据2
```

不同线程拥有不同的 `ThreadLocalMap`，所以能够保存各自独立的数据。不过“变量副本”是一种便于理解的说法，`ThreadLocal` 并不一定真的把原对象复制一份，而是每个线程分别保存一个值。

补充解析：

`ThreadLocal` 不是线程，也不是任务，它是“线程本地变量”的工具。它的核心目的不是共享，而是隔离：每个线程通过同一个 `ThreadLocal` 对象访问到的是自己线程里的那份值。

注意一点：`ThreadLocal` 用完后最好调用 `remove()`，尤其在线程池中，否则线程复用时可能造成旧数据残留，甚至引发内存泄漏风险。

记忆点：线程间共享用同步机制；线程内隔离用 `ThreadLocal`。
