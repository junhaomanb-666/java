## Java-001 方法重载

**题目：**

下面有关重载函数的说法中正确的是？

**选项：**

- A. 重载函数必须具有不同的返回值类型
- B. 重载函数形参个数必须不同
- C. 重载函数必须有不同的形参列表
- D. 重载函数名可以不同

**正确答案：** C

**你的答案：** 未记录

**解析：**

方法重载发生在同一个类中，要求方法名相同，参数列表不同。参数列表不同可以体现为参数个数不同、参数类型不同、参数顺序不同。

返回值类型不能单独作为重载依据。

**考点：**

- 方法重载
- 参数列表

**易错点：**

- 方法名必须相同
- 只改返回值类型不构成重载

## Java-002 向上转型与向下转型

**题目：**

给出如下代码：

```java
interface Foo {}

class Alpha implements Foo {}

class Beta extends Alpha {}

class Delta extends Beta {
    public static void main(String[] args) {
        Beta x = new Beta();
        // 此处插入代码
    }
}
```

以下选项中，将哪个插入上述代码的位置，会导致程序抛出 `java.lang.ClassCastException` 异常？

**选项：**

- A. `Alpha a = x;`
- B. `Foo f = (Delta) x;`
- C. `Foo f = (Alpha) x;`
- D. `Beta b = (Beta) (Alpha) x;`

**正确答案：** B

**你的答案：** 未记录

**解析：**

`x` 的实际对象类型是 `Beta`。

A 是向上转型，`Beta` 转成父类 `Alpha`，安全。

C 先转成 `Alpha`，再赋给接口 `Foo` 引用，实际对象 `Beta` 继承自实现了 `Foo` 的 `Alpha`，安全。

D 先向上转为 `Alpha`，再向下转回 `Beta`。对象实际类型本来就是 `Beta`，安全。

B 把实际类型为 `Beta` 的对象强转成子类 `Delta`。父类对象不能强制转成并非其真实类型的子类对象，因此运行时抛出 `ClassCastException`。

**考点：**

- 向上转型
- 向下转型
- 运行时实际类型
- `ClassCastException`

**易错点：**

- 编译能通过，不代表运行时类型转换一定成功
- 向下转型必须满足对象实际类型是目标类型或其子类

## Java-003 位运算输出

**题目：**

以下 Java 程序代码的输出是？

```java
public static void main(String args[]) {
    System.out.println(14 ^ 3);
}
```

**选项：**

截图未保留完整选项；原文件记录答案为 `13`。

**正确答案：** `13`

**你的答案：** 未记录

**解析：**

`^` 是按位异或。相同为 0，不同为 1。

```text
14 = 1110
 3 = 0011
---------
     1101 = 13
```

所以输出：

```text
13
```

**考点：**

- 按位异或 `^`
- 二进制运算

**易错点：**

- `^` 在 Java 中不是幂运算
- `&&`、`||` 是逻辑运算，`&`、`|`、`^` 是位运算或布尔逻辑运算

## Java-004 `short` 运算与复合赋值

**题目：**

在 Java 中，下列语句会运行有误的是？

**选项：**

- A. `short s = 2; s = s + 2;`
- B. `short s = 2; s += 2;`
- C. `short s = 2; s++;`
- D. `short s = 2; s = s + (short)2;`

**正确答案：** A、D

**你的答案：** 未记录

**解析：**

A 错误。`s + 2` 中 `short` 会自动提升为 `int`，结果为 `int`，不能直接赋值给 `short`。

D 错误。即使右边写成 `(short)2`，`s + (short)2` 仍会发生数值提升，结果仍是 `int`。

B 正确。`s += 2` 是复合赋值，内部包含隐式强制类型转换，近似等价于：

```java
s = (short) (s + 2);
```

C 正确。`s++` 对变量自身做自增，也会隐式完成类型处理。

**考点：**

- 小整数类型自动提升
- 复合赋值
- 自增运算

**易错点：**

- `byte`、`short`、`char` 运算都会自动提升为 `int`
- `s += 2` 和 `s = s + 2` 不完全等价

## Java-005 Java 编译过程

**题目：**

在 Java 编程中，Java 编译器会将 Java 程序转换为？

**选项：**

- A. 字节码
- B. 可执行代码
- C. 机器代码
- D. 以上都不对

**正确答案：** A

**你的答案：** 未记录

**解析：**

Java 编译器 `javac` 会把 `.java` 源代码编译成 `.class` 字节码文件。

类加载到 JVM 后，执行引擎解释执行或通过 JIT 编译，把热点字节码编译成本地机器码执行。

**考点：**

- `.java`
- `.class`
- 字节码
- JVM 执行引擎
- JIT

**易错点：**

- Java 编译器不是直接生成机器码
- 字节码由 JVM 负责解释或即时编译执行

## Java-006 子类构造方法与父类构造方法

**题目：**

以下程序的输出结果为？

```java
class Demo {
    public Demo(String s) {
        System.out.print("hello");
    }
}

public class Test extends Demo {
    public Test(String s) {
        System.out.print("world");
    }

    public static void main(String[] args) {
        new Test("hello world");
    }
}
```

**选项：**

- A. `world`
- B. `hello`
- C. `hello world`
- D. 编译错误

**正确答案：** D

**你的答案：** 未记录

**解析：**

子类构造方法必须先调用父类构造方法。如果子类构造方法中没有显式写 `super(...)`，编译器会默认插入：

```java
super();
```

但父类 `Demo` 只定义了有参构造方法 `Demo(String s)`，没有无参构造方法，所以 `super()` 找不到对应构造方法，编译错误。

正确写法：

```java
public Test(String s) {
    super(s);
    System.out.print("world");
}
```

此时输出会是：

```text
helloworld
```

**考点：**

- 构造方法
- `super(...)`
- 默认无参构造

**易错点：**

- 只要定义了有参构造，编译器就不会再自动提供无参构造
- 子类构造第一步必须调用父类构造

## Java-007 字符串数组转 `ArrayList`

**题目：**

Java 中，有如下字符串数组：

```java
String[] str = new String[] {"aaa", "bbb", "ccc"};
```

则以下哪些语句可以正确地将 `String` 数组 `str` 转成 `ArrayList`？

**选项：**

- A. `List<String> list = new ArrayList<String>(); for (String string : str) { list.add(string); }`
- B. `List<String> list = new ArrayList<String>(Arrays.asList(str));`
- C. `List<String> list = Arrays.asList(str);`
- D. `List<String> list = new ArrayList<String>(); Collections.addAll(list, str);`

**正确答案：** A、B、D

**你的答案：** 未记录

**解析：**

A 正确，手动遍历数组并逐个加入新建的 `ArrayList`。

B 正确，`Arrays.asList(str)` 先得到一个固定大小的 List，再用 `new ArrayList<>(...)` 包装为真正可增删的 `ArrayList`。

D 正确，`Collections.addAll(list, str)` 可以把数组元素加入目标集合。

C 不符合题意。`Arrays.asList(str)` 返回的是固定大小的 `List`，实际类型是 `java.util.Arrays$ArrayList`，不是 `java.util.ArrayList`。如果后续增删元素，会抛出 `UnsupportedOperationException`。

**考点：**

- 数组转集合
- `Arrays.asList()`
- `Collections.addAll()`
- `ArrayList`

**易错点：**

- 题目问的是转成 `ArrayList`，不是只要得到一个 `List`
- `Arrays.asList()` 返回固定长度列表
