## Java-001 类之间的常见关系

**题目：**

类之间存在以下几种常见的关系？

**选项：**

- A. `"USES-A"` 关系
- B. `"HAS-A"` 关系
- C. `"IS-A"` 关系
- D. `"INHERIT-A"` 关系

**正确答案：** A、B、C

**你的答案：** B、C

**原文件解析：**

原文件仅包含题目截图，未提供额外文字解析或解析图片。

**我的补充解析：**

面向对象中常见的类关系包括：

- `USES-A`：使用关系，也常说依赖关系。一个类在方法中临时使用另一个类，例如方法参数、局部变量。
- `HAS-A`：拥有关系，也常说关联/聚合/组合。一个类中持有另一个类作为成员变量。
- `IS-A`：是一个关系，也就是继承或接口实现。子类对象可以看作父类对象。

`INHERIT-A` 不是常见标准说法。继承关系通常归入 `IS-A`。

示例：

```java
class Engine {}

class Car extends Vehicle {     // Car IS-A Vehicle
    private Engine engine;      // Car HAS-A Engine

    void repair(Mechanic m) {   // Car USES-A Mechanic
        m.fix(this);
    }
}
```

**考点：**

- `USES-A`
- `HAS-A`
- `IS-A`
- 依赖、关联、继承

**易错点：**

- 继承关系标准表述是 `IS-A`
- `INHERIT-A` 不是常见的面向对象关系分类
- 多选题容易少选 `USES-A`
