## DB-001 `SELECT INTO` 与 `INSERT INTO SELECT`

**题目：**

某打车公司要将驾驶里程 `drivedistanced` 超过 5000 里的司机信息转存到一张称为 `seniordrivers` 的表中，他们的详细情况被记录在表 `drivers` 中，正确的 SQL 语句为？

**选项：**

- A. `insert into seniordrivers drivedistanced >= 5000 from drivers where`
- B. `insert seniordrivers (drivedistanced) values from drivers where drivedistanced >= 5000`
- C. `insert into seniordrivers (drivedistanced) values >= 5000 from drivers where`
- D. `select * into seniordrivers from drivers where drivedistanced >= 5000`

**正确答案：** D

**你的答案：** C

**原文件解析：**

`select into from` 要求目标表不存在，因为在插入时会自动创建。

`insert into select from` 要求目标表存在。

`INSERT INTO` 语句用于向一张表中插入新的行。

`SELECT INTO` 语句从一张表中选取数据插入到另一张表中。常用于创建表的备份复件或者用于对记录进行存档。

**我的补充解析：**

本题中 `seniordrivers` 被描述为“转存到一张称为 seniordrivers 的表中”，题库语境默认是要用查询结果创建并填充新表，因此使用：

```sql
select *
into seniordrivers
from drivers
where drivedistanced >= 5000;
```

如果 `seniordrivers` 已经存在，则应使用：

```sql
insert into seniordrivers
select *
from drivers
where drivedistanced >= 5000;
```

**考点：**

- `SELECT INTO`
- `INSERT INTO ... SELECT`
- 新表创建与已有表插入

**易错点：**

- `SELECT INTO` 会创建目标表
- `INSERT INTO SELECT` 要求目标表已经存在

## DB-002 事务与并发控制

**题目：**

下列选项关于事务和并发控制的描述不正确的是？

**选项：**

- A. 并发控制机制的好坏是衡量一个数据库管理系统性能的重要标志之一
- B. 可串行性是判断并发事务是否正确的准则
- C. SQL Server 中每一条 `select`、`insert`、`update`、`delete` 语句都是显性事务的一部分
- D. 事务的隔离级别越高，并发能力也就越低

**正确答案：** C

**你的答案：** B

**原文件解析：**

在 SQL Server 默认的自动提交模式（autocommit）下，每条 `select` / `insert` / `update` / `delete` 会作为“隐式事务”自动开始并在语句结束后自动提交；只有显式使用 `BEGIN TRANSACTION ... COMMIT/ROLLBACK` 的才是“显性事务”。因此“每一条语句都是显性事务的一部分”不对。

**我的补充解析：**

B 是正确说法。并发事务调度如果等价于某个串行调度，通常认为结果是正确的，这就是可串行性。

C 错在“显性事务”。SQL Server 默认自动提交下，单条 DML/查询语句确实会被事务保护，但属于隐式事务或自动提交事务，不是显式写出来的事务。

D 正确。隔离级别越高，锁或版本控制限制通常越强，并发度往往越低。

**考点：**

- 自动提交
- 显式事务
- 隐式事务
- 可串行性
- 隔离级别与并发能力

**易错点：**

- “每条语句有事务语义”不等于“每条语句都是显性事务”
