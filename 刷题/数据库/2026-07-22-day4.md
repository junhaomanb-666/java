## DB-001 表关联与左连接行数

**题目：**

表关联时，以下哪种说法是正确的？

**选项：**

- A. 左连接时，结果集数据的行数一定等于左表
- B. 左连接时，结果集数据的行数一定等于右表
- C. 右连接时，结果集数据的行数一定等于右表
- D. 左连接时，结果集的行数可能大于左表的行数

**正确答案：** D

**你的答案：** A

**解析：**

左连接会保留左表的所有行，但不代表结果行数一定等于左表行数。

如果左表一行在右表中匹配到多行，就会产生多行结果。例如左表 1 个学生，右表有这个学生的 2 条成绩记录，左连接后会得到 2 行。因此左连接结果行数可能大于左表。

**考点：**

- `LEFT JOIN`
- 一对多关联
- 结果集行数

**易错点：**

- “保留左表所有行”不等于“结果行数等于左表行数”

## DB-002 查询当月订单

**题目：**

MySQL 中有一张订单表 `order_info_table`，其中有字段 `create_time` 表示订单创建时间，现要查看当月创建的订单信息，以下 SQL 语句正确的是？

**选项：**

- A. `SELECT * FROM order_info_table where DATE_SUB(CURDATE(), INTERVAL 30 DAY) <= date(create_time)`
- B. `SELECT * FROM order_info_table WHERE create_time = DATE_FORMAT(CURDATE(),'%Y%m')`
- C. `SELECT * FROM order_info_table WHERE DATE_FORMAT(create_time,'%Y%m') = DATE_FORMAT(CURDATE(),'%Y%m')`
- D. `SELECT * FROM order_info_table WHERE DATE_FORMAT(create_time,'%m') = DATE_FORMAT(CURDATE(),'%m')`

**正确答案：** C

**你的答案：** A

**解析：**

题目要求查询“当月”订单，应同时比较年份和月份：

```sql
DATE_FORMAT(create_time, '%Y%m') = DATE_FORMAT(CURDATE(), '%Y%m')
```

A 查询的是最近 30 天，不等于自然月。例如 7 月 22 日往前 30 天会跨到 6 月。

B 左边是完整日期时间，右边是类似 `202607` 的字符串，比较没有实际意义。

D 只比较月份，不比较年份，会把不同年份的同月数据也查出来。

**考点：**

- `DATE_FORMAT()`
- 当月数据筛选
- 最近 30 天与自然月的区别

**易错点：**

- 查询当月要比较 `%Y%m`，不要只比较 `%m`
- “最近 30 天”不等于“本月”

## DB-003 未完成与已完成订单合并统计

**题目：**

将两个结果集：未完成订单 `order_status = 0` 和已完成订单 `order_status = 1` 合并为一列统计，应使用？

**选项：**

- A. `UNION ALL` 配合 `CASE WHEN`
- B. `JOIN ON` 条件
- C. `WHERE` 多个 `OR` 条件
- D. `GROUP BY ROLLUP`

**正确答案：** A

**你的答案：** C

**解析：**

题目要求把未完成订单和已完成订单分别统计后合并成一列结果，适合使用 `UNION ALL` 把两个统计结果纵向合并。

**原文件解析图片：**

![订单状态合并统计解析](D:/Workspace/刷题/解析图片/day4/订单状态合并统计解析.png)

示例：

```sql
SELECT '未完成' AS status, COUNT(*) AS count
FROM orders
WHERE order_status = 0
UNION ALL
SELECT '已完成' AS status, COUNT(*) AS count
FROM orders
WHERE order_status = 1;
```

`WHERE order_status = 0 OR order_status = 1` 只能筛选这两类订单，不能直接生成“未完成/已完成”两行统计结果。

补充：也可以用 `GROUP BY + CASE WHEN` 做类似统计：

```sql
SELECT
    CASE
        WHEN order_status = 0 THEN '未完成'
        ELSE '已完成'
    END AS status,
    COUNT(*) AS count
FROM orders
WHERE order_status IN (0, 1)
GROUP BY order_status;
```

但按本题选项，正确答案是 A。

**考点：**

- `UNION ALL`
- 条件统计
- `CASE WHEN`

**易错点：**

- `WHERE` 只负责筛选，不负责把不同统计结果合并成多行
- `UNION ALL` 不去重，适合合并统计结果
