## DB-001 创建唯一索引

**题目：**

使用哪条 SQL 语句可以在 `Student` 表的 `LastName` 列上创建名为 `SIndex` 的唯一索引？

**选项：**

- A. `CREATE INDEX SIndexON Student (LastName)`
- B. `CREATE UNIQUE INDEX SIndexON Student (LastName)`
- C. `CREATE INDEX (SIndex)ON Student (LastName)`
- D. `CREATE UNIQUE INDEX (SIndex)ON Student (LastName)`

**正确答案：** B

**你的答案：** D

**解析：**

创建唯一索引应使用：

```sql
CREATE UNIQUE INDEX index_name
ON table_name (column_name);
```

本题对应：

```sql
CREATE UNIQUE INDEX SIndex
ON Student (LastName);
```

题目选项里写作 `SIndexON`，应理解为 `SIndex ON`。D 错在索引名不应写在括号中。

**考点：**

- `CREATE UNIQUE INDEX`
- 索引名
- 表名与列名

**易错点：**

- `UNIQUE` 不能漏
- 索引名不需要加括号

## DB-002 `READ COMMITTED` 隔离级别

**题目：**

在一个事务中，先后执行以下操作：

1. `SELECT 库存 FROM 商品 WHERE id = 101`，结果为 10
2. `UPDATE 商品 SET 库存 = 9 WHERE id = 101`
3. `COMMIT`

此时另一个并发事务在步骤 1 后立即查询同一商品库存，`READ COMMITTED` 隔离级别下会返回什么？

**选项：**

- A. 立即返回 9
- B. 等待第一个事务提交后返回 10
- C. 等待第一个事务提交后返回 9
- D. 立即返回 10

**正确答案：** D

**你的答案：** A

**原文件解析：**

| 隔离级别 | 返回结果 | 原因 |
| --- | --- | --- |
| `READ UNCOMMITTED` | 立即返回 9 | 允许脏读 |
| `READ COMMITTED` | 立即返回 10 | 避免脏读，读已提交版本 |
| `REPEATABLE READ` | 立即返回 10 | 读事务开始时的快照 |
| `SERIALIZABLE` | 可能等待或立即返回 10 | 依赖锁机制 |

**我的补充解析：**

`READ COMMITTED` 只能读到已经提交的数据。第一个事务虽然已经把库存更新为 9，但尚未 `COMMIT`，所以另一个事务不能读到未提交的 9，而是读到已提交版本 10。

**考点：**

- `READ COMMITTED`
- 脏读
- 已提交读
- 并发事务

**易错点：**

- 已执行 `UPDATE` 不代表其他事务马上能读到
- `READ COMMITTED` 会避免脏读
