## 题目 1：INNER JOIN 与 COUNT(列名)

MySQL 中表 `student_table(id, name, birth, sex)`，插入如下记录：

```sql
('1003', '',     '2000-01-01', '男');
('1004', '张三', '2000-08-06', '男');
('1005', NULL,   '2001-12-01', '女');
('1006', '张三', '2000-08-06', '女');
('1007', '王五', '2001-12-01', '男');
('1008', '李四', NULL,         '女');
('1009', '李四', NULL,         '男');
('1010', '李四', '2001-12-01', '女');
```

执行：

```sql
SELECT COUNT(t2.birth) AS c1
FROM (
  SELECT * FROM student_table WHERE sex = '男'
) t1
INNER JOIN (
  SELECT * FROM student_table WHERE sex = '女'
) t2
ON t1.birth = t2.birth AND t1.name = t2.name;
```

结果行数是？

正确答案：1

原解析：

答案：1。

两点需要注意：

1. `NULL = NULL` 结果不是 `TRUE`，因此不能匹配。
2. `COUNT(t2.birth)` 只统计非 `NULL` 值。

所以查询返回 1 行，`c1` 的值也是 1。

补充解析：

先看男女表能否按 `birth` 和 `name` 同时匹配：

| 男生 | 女生 | 是否匹配 |
| --- | --- | --- |
| 1004 张三 2000-08-06 | 1006 张三 2000-08-06 | 匹配 |
| 1007 王五 2001-12-01 | 1005 NULL 2001-12-01 | 姓名不匹配 |
| 1009 李四 NULL | 1008 李四 NULL | `NULL = NULL` 不是 `TRUE`，不匹配 |
| 1009 李四 NULL | 1010 李四 2001-12-01 | 出生日期不匹配 |

真正匹配成功的只有一条：`1004 张三` 与 `1006 张三`。

并且匹配成功的这条记录中，`t2.birth = '2000-08-06'`，不是 `NULL`，所以：

```sql
COUNT(t2.birth) = 1
```

另外，聚合函数 `COUNT(...)` 没有 `GROUP BY` 时，整个查询结果会返回一行聚合结果。所以题目问“结果行数”时，最终也是 1 行。

记忆点：

- `NULL = NULL` 不成立，应使用 `IS NULL` 判断空值。
- `COUNT(*)` 统计行数。
- `COUNT(列名)` 只统计该列非 `NULL` 的行。
