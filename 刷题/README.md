# 刷题资料库

这个文件夹用于按方向保存每日刷题总结。

## 目录规则

- `Java/`：Java 基础、集合、并发、JVM、IO、网络编程等题目
- `数据库/`：MySQL、SQL、事务、索引、锁、优化等题目
- `计算机基础/`：服务器、网络基础、操作系统、通用计算机知识等题目
- `原始材料/`：你每天发来的原 Markdown 文件原样归档，截图链接、远程图片、原始解析、补充代码都不能丢
- 以后如果出现新方向，例如算法、计算机网络、操作系统，会继续新建同名分类文件夹

## 文件命名

每日总结文件统一使用：

```text
YYYY-MM-DD-dayN.md
```

例如：

```text
2026-07-20-day1.md
```

## 每题整理格式

每道题都必须保留完整题卡，不能只写答案或解析：

```text
题目：
选项：
正确答案：
你的答案：
原文件解析：
原文件解析图片：
我的补充解析：
考点：
易错点：
```

如果题目来自截图，我会先把截图中的题干、代码和选项转写成文字，不在分类题卡里重复放题目截图。

重要规则：

- 你给我的源文件内容必须完整保留一份到 `原始材料/`
- 分类笔记里题目图片必须提取成文字题目和文字选项
- 源文件中的解析图片必须用 Markdown 图片语法原封不动嵌入，例如 `![解析图](图片地址)`，不能只写路径，不能放在代码块里
- 源文件中已有的文字解析、代码块和补充说明不能省略
- 我的总结只能作为补充，不能替代或吞掉原文件内容

## 每次总结后的固定动作

每次我整理完当天题目后，会提醒你：

- 今天要复习哪一天
- 明天要复习哪一天
- 哪些错题需要优先二刷
