# ALL、ANY、SOME 子查询比较

## 问题

`ALL()`、`ANY()`、`SOME()` 有什么区别？

## 分类

SQL查询结构

## 回答

`ALL` 表示必须满足子查询中的所有结果，整个条件才成立。

常见等价理解：

```sql
>= ALL(...) 等价于 大于等于最大值
<= ALL(...) 等价于 小于等于最小值
```

`ANY` 表示只要满足子查询中的任意一条结果，整个条件就成立。

常见等价理解：

```sql
> ANY(...) 等价于 大于最小值
< ANY(...) 等价于 小于最大值
```

`SOME` 和 `ANY` 作用相同。

## 总结

`ALL` 看全部，`ANY` / `SOME` 看任意一个。
