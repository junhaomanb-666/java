# 日期时间函数

## 问题

`CURDATE()`、`NOW()`、`DATE_FORMAT()`、`DATE()`、`DATE_SUB()` 分别是什么？

## 分类

SQL函数

## 回答

`CURDATE()` 返回当前日期，不包含时分秒。

```sql
SELECT CURDATE();
```

示例结果：

```text
2026-07-22
```

`NOW()` 返回当前日期和时间。

```sql
SELECT NOW();
```

示例结果：

```text
2026-07-22 10:30:00
```

`DATE_FORMAT(日期, 格式)` 用来把日期按指定格式转成字符串。

```sql
SELECT DATE_FORMAT('2026-07-22 10:30:00', '%Y%m');
```

结果：

```text
202607
```

常见格式：

| 格式 | 含义 | 示例 |
| --- | --- | --- |
| `%Y` | 四位年份 | 2026 |
| `%y` | 两位年份 | 26 |
| `%m` | 两位月份 | 07 |
| `%d` | 两位日期 | 22 |
| `%H` | 小时 | 10 |
| `%i` | 分钟 | 30 |
| `%s` | 秒 | 00 |

`DATE()` 用来从日期时间中取出日期部分。

```sql
SELECT DATE('2026-07-22 10:30:00');
```

结果：

```text
2026-07-22
```

`DATE_SUB()` 用来让日期减去一段时间。

```sql
DATE_SUB(日期, INTERVAL 数值 单位)
```

示例：

```sql
SELECT DATE_SUB(CURDATE(), INTERVAL 30 DAY);
```

如果当前日期是 `2026-07-22`，结果是：

```text
2026-06-22
```

## 总结

日期函数主要分三类：取当前时间、格式化日期、截取日期、对日期做加减。
