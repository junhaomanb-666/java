# Java IO

## 1. Java IO 分为哪几类？

**答案：** 按数据单位分为字节流和字符流；按流向分为输入流和输出流；按功能分为节点流和处理流。

**核心记忆：**

- 字节流：`InputStream` / `OutputStream`
- 字符流：`Reader` / `Writer`

## 2. 字节流和字符流的区别？

**答案：** 字节流处理 8 位字节，适合图片、视频等二进制文件；字符流处理字符，适合文本，内部会进行编码转换，能减少乱码问题。

## 3. 什么是节点流和处理流？

**答案：** 节点流直接和数据源交互，例如 `FileInputStream`；处理流包装节点流以增强功能，例如 `BufferedInputStream`。处理流体现了装饰器模式。

## 4. 什么是缓冲区？有什么作用？

**答案：** 缓冲区是内存中的临时存储区域，可以减少实际 IO 次数，提高读写性能。

## 5. 什么是 Java 序列化？如何实现？

**答案：** 序列化是把对象转换为字节流，便于存储或网络传输。实现方式是让类实现 `Serializable` 接口，并使用 `ObjectOutputStream` 和 `ObjectInputStream` 进行写入和读取。

## 6. 字节流如何转为字符流？

**答案：** 字节输入流转字符流使用 `InputStreamReader`；字节输出流转字符流使用 `OutputStreamWriter`。

## 7. NIO 和 IO 的主要区别？

**答案：** 传统 IO 面向流，通常是阻塞的；NIO 面向缓冲区，支持非阻塞和 `Selector` 多路复用。

**核心记忆：**

- IO：面向流
- NIO：面向缓冲区，支持非阻塞

## 8. FileInputStream 的 read() 为什么返回 int 而不是 byte？

**答案：** 因为 `read()` 需要用 `-1` 表示流结束。如果返回 `byte`，就无法区分真实数据 `0xFF` 和结束标记 `-1`。

## 9. 字符流本质是什么？

**答案：** 字符流本质上是字节流加编码表，读取文本时自动完成字节到字符的转换。

## 10. System.out.println 是什么？

**答案：** `out` 是 `System` 类中的静态成员变量，类型是 `PrintStream`；`println` 是 `PrintStream` 类的方法。
