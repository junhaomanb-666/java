# JVM

> 本文件用于整理 JVM、垃圾回收、类加载、内存模型等相关面试题。

## 1. Java GC 是什么？

**通俗理解：** GC 就是 JVM 自带的“内存清洁工”。Java 程序创建对象后，不需要像 C/C++ 那样手动释放内存；当对象没人用了，GC 会在合适的时候把它占用的内存回收掉。

**专业回答：** GC 是 Garbage Collection，垃圾回收。它负责自动识别不再被引用的对象，并回收这些对象占用的堆内存。Java GC 主要关注堆内存中的对象回收，判断对象是否存活常见方式有引用计数法和可达性分析法，JVM 主流使用可达性分析。常见垃圾回收算法包括标记-清除、复制、标记-整理、分代收集等。

**常见流程：**

1. 从 GC Roots 出发做可达性分析。
2. 找出不可达对象。
3. 根据具体垃圾回收器和回收算法清理对象。
4. 必要时整理内存，减少内存碎片。

**常见 GC Roots：**

- 虚拟机栈中引用的对象
- 方法区中类静态属性引用的对象
- 方法区中常量引用的对象
- 本地方法栈中 JNI 引用的对象
- 正在运行线程相关的对象

**记忆版：** GC = JVM 自动回收不用的堆对象；核心是“判断存活 + 回收内存”。

**面试补充：**

- Minor GC：主要回收新生代。
- Major GC / Old GC：主要回收老年代。
- Full GC：通常回收整个堆和方法区相关区域，成本较高，应尽量减少频繁 Full GC。
