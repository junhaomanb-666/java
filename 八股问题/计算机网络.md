# 计算机网络

## 1. TCP 三次握手和四次挥手是什么？

**通俗理解：** 三次握手是客户端和服务端在通信前互相确认“我能发、你能收、你也能发、我也能收”。四次挥手是双方分别关闭自己的发送通道，因为 TCP 是全双工通信，两个方向要分别关闭。

**专业回答：**

三次握手：

1. 客户端发送 `SYN`，请求建立连接。
2. 服务端回复 `SYN + ACK`，表示收到请求并同意连接。
3. 客户端发送 `ACK`，表示确认服务端响应，连接建立。

四次挥手：

1. 主动关闭方发送 `FIN`，表示自己没有数据要发了。
2. 被动关闭方回复 `ACK`，表示收到关闭请求。
3. 被动关闭方数据发送完后，再发送 `FIN`。
4. 主动关闭方回复 `ACK`，连接最终关闭。

**为什么握手是三次：** 两次不够确认双方收发能力，三次可以确认客户端和服务端的发送、接收能力都正常。

**为什么挥手是四次：** TCP 是全双工，关闭发送和关闭接收需要分别确认。被动关闭方收到 `FIN` 后，可能还有数据没发完，所以 `ACK` 和 `FIN` 通常分开发。

**记忆版：** 握手三次确认能不能通信；挥手四次分别关闭两个方向。
