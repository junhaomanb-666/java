# Java 面向对象

## 1. 面向对象的三大特性是什么？

**答案：** 封装、继承、多态。

## 2. 类和对象的区别？

**答案：** 类是对事物的抽象描述，是对象的模板；对象是类的具体实例，会占用内存。

## 3. 方法重载和重写的区别？

**答案：** 重载发生在同一个类中，方法名相同，参数列表不同；重写发生在父子类之间，子类重新定义父类方法，方法签名相同。

## 4. 什么是封装？为什么要封装？

**答案：** 封装是将属性私有化，并通过公共方法对外访问。目的是保护数据安全，提高代码可维护性。

## 5. 构造方法的特点？

**答案：** 构造方法名与类名相同，没有返回值，可以重载，创建对象时自动调用，每个对象创建时通常只调用一次对应构造方法。

## 6. this 关键字的作用？

**答案：** `this` 表示当前对象，可以区分成员变量和局部变量，也可以调用本类其他构造方法。

## 7. 一个 .java 文件可以有多个类吗？

**答案：** 可以有多个类，但最多只能有一个 `public` 类，并且 `public` 类名必须与文件名一致。

## 8. 抽象类和接口的区别？

**答案：** 抽象类可以有抽象方法和具体方法，只能单继承；接口主要定义规范，Java 8 后可以有默认方法和静态方法，一个类可以实现多个接口。

## 9. String、StringBuffer、StringBuilder 的区别？

**答案：** `String` 不可变，线程安全；`StringBuffer` 可变，线程安全，方法使用 `synchronized`；`StringBuilder` 可变，线程不安全，但效率通常最高。

## 10. 多态的实现前提？

**答案：** 继承、方法重写、父类引用指向子类对象。

## 11. 面向过程和面向对象有什么区别？

**通俗理解：** 面向过程更关注“先做什么、再做什么”，像写菜谱步骤；面向对象更关注“谁来做、谁有什么能力”，像安排不同角色协作。

**专业回答：** 面向过程以函数和执行流程为中心，适合逻辑简单、步骤明确的场景。面向对象以对象为中心，将数据和行为封装在对象中，通过封装、继承、多态提高代码复用性、扩展性和维护性。Java 是典型面向对象语言。

**记忆版：** 面向过程看步骤，面向对象看对象和职责。

## 12. 内部类的优点是什么？

**通俗理解：** 内部类就是把一个类放到另一个类里面。它适合表达“这个类只为外部类服务”的关系，让代码更集中，也能方便访问外部类成员。

**专业回答：** 内部类可以增强封装性，将只在外部类内部使用的逻辑隐藏起来；可以直接访问外部类的成员，包括私有成员；可以让代码结构更贴近业务关系；还可以在一些回调、事件监听、策略封装场景中让实现更简洁。

**记忆版：** 内部类优点：封装强、访问方便、结构清晰、适合回调。

## 13. 普通类和抽象类有哪些区别？

**通俗理解：** 普通类像可以直接使用的成品；抽象类像半成品模板，里面可以规定子类必须完成哪些能力。

**专业回答：** 普通类可以直接创建对象，方法通常有完整实现。抽象类使用 `abstract` 修饰，不能直接实例化，可以包含抽象方法和普通方法。抽象方法只有声明没有方法体，必须由非抽象子类实现。抽象类适合抽取多个子类的共同属性和行为，同时保留部分必须由子类定制的能力。

**记忆版：** 普通类能 `new`，抽象类不能直接 `new`；抽象类负责“抽共同点、留扩展点”。

## 14. 抽象类能使用 final 修饰吗？

**通俗理解：** 不能。抽象类就是希望被继承，`final` 又表示不能被继承，两者目标冲突。

**专业回答：** 抽象类不能被 `final` 修饰。`abstract` 表示类中可能存在未实现的抽象方法，需要子类继承并实现；`final` 表示该类不能被继承。如果同时使用，会导致抽象方法无法被实现，因此编译不通过。

**记忆版：** `abstract` 要继承，`final` 禁继承；两个不能一起用。

## 15. 创建对象用什么关键字？对象实例与对象引用有什么不同？

**通俗理解：** 创建对象用 `new`。对象实例是真正在堆内存里的那份数据；对象引用是手里拿着的“地址牌”，通过它才能找到对象。

**专业回答：** Java 中通常使用 `new` 关键字创建对象实例，例如 `User user = new User();`。`new User()` 创建的是对象实例，存储在堆内存中；`user` 是对象引用，存储在栈帧的局部变量表中，保存对象地址的引用信息。一个对象可以被多个引用指向，一个引用也可以重新指向其他对象。

**记忆版：** `new` 出实例，变量拿引用；实例在堆，引用通常在栈。

## 16. 在 Java 中定义一个不做事且没有参数的构造方法有什么作用？

**通俗理解：** 无参构造像给对象留一个“默认入口”，很多框架创建对象时会先走这个入口，再通过反射或 setter 填数据。

**专业回答：** 无参构造方法用于支持默认创建对象，便于子类构造时隐式调用父类构造，也便于反射、序列化、ORM 框架等工具创建对象。如果类中没有定义任何构造方法，编译器会自动生成一个默认无参构造；但只要手写了有参构造，编译器就不会再自动生成无参构造，此时如果框架或子类需要无参构造，就必须显式声明。

**记忆版：** 无参构造 = 默认创建入口；写了有参构造后，默认无参就没了。

## 17. 调用子类构造方法前为什么会先调用父类无参构造方法？

**通俗理解：** 子类对象里包含父类那部分内容，先把父类部分初始化好，子类才能在这个基础上继续初始化。

**专业回答：** Java 创建子类对象时，会先完成父类成员的初始化，再执行子类成员初始化。若子类构造方法中没有显式写 `super(...)`，编译器会默认在第一行插入 `super()`，调用父类无参构造。这样可以保证继承链上的父类状态先被正确构造。如果父类没有无参构造，子类必须显式调用父类已有的有参构造。

**记忆版：** 先父后子；不写 `super(...)`，默认调用 `super()`。

## 18. 构造方法的作用是什么？没有声明构造方法程序能正确执行吗？

**通俗理解：** 构造方法负责对象刚出生时的初始化。即使你不写，Java 也会帮你补一个默认无参构造，所以程序通常能运行。

**专业回答：** 构造方法用于在创建对象时初始化对象状态，可以给成员变量赋初值、校验参数、建立必要依赖。如果一个类没有声明任何构造方法，编译器会自动生成一个默认无参构造方法，因此程序可以正确编译和执行。但如果已经声明了任意构造方法，编译器就不会再自动生成默认无参构造。

**记忆版：** 构造方法管初始化；一个不写，编译器补；写了一个，就不再补默认无参。

## 19. 构造方法有哪些特性？

**通俗理解：** 构造方法名字必须和类名一样，创建对象时自动调用，不能像普通方法那样写返回值。

**专业回答：** 构造方法的方法名必须与类名一致；没有返回值类型，连 `void` 也不能写；创建对象时由 JVM 自动调用；可以重载；不能被继承，因此也不能被重写；可以使用访问修饰符控制创建对象的范围；构造方法第一行可以调用 `this(...)` 或 `super(...)`，但二者不能同时出现。

**记忆版：** 同类名、无返回、可重载、不可继承、创建时自动调。

## 20. 什么是内部类？

**通俗理解：** 内部类就是定义在另一个类里面的类，适合表达“这个类只服务于外部类”的关系。

**专业回答：** 内部类是定义在类、方法或代码块内部的类。常见内部类包括成员内部类、静态内部类、局部内部类和匿名内部类。内部类可以增强封装性，让相关逻辑更集中；成员内部类可以访问外部类成员，包括私有成员；静态内部类不依赖外部类对象，常用于工具结构、构建器模式等场景。

**记忆版：** 内部类四类：成员、静态、局部、匿名；作用是封装相关逻辑。

## 21. 在静态方法内调用非静态成员为什么是非法的？

**通俗理解：** 静态方法属于类，类加载后就能用；非静态成员属于具体对象。没有对象时，静态方法不知道该访问哪个对象的成员。

**专业回答：** 静态方法可以通过类名直接调用，不依赖具体对象；非静态成员必须依赖对象实例存在。静态方法执行时可能还没有任何对象被创建，因此不能直接访问非静态属性或非静态方法。若要访问，必须先创建对象，再通过对象引用调用。

**记忆版：** 静态属于类，非静态属于对象；没有对象，就不能直接调非静态。

## 22. 什么是方法的返回值？返回值有什么作用？

**通俗理解：** 返回值就是方法执行完交回来的结果。比如查询余额的方法，返回值就是余额。

**专业回答：** 方法返回值是方法执行完成后返回给调用方的数据，返回值类型由方法声明指定。返回值可以用于传递计算结果、查询结果或执行状态。若方法不需要返回数据，使用 `void`。非 `void` 方法必须通过 `return` 返回与声明类型兼容的值。

**记忆版：** 返回值 = 方法交回的结果；不需要结果就用 `void`。

## 23. this 和 super 的用法分别是什么？

**通俗理解：** `this` 指当前对象自己，`super` 指父类那部分。当前类和父类有同名变量或方法时，它们能帮你说清楚到底找谁。

**专业回答：** `this` 表示当前对象，可以访问当前类成员、区分成员变量和局部变量、在构造方法中调用本类其他构造方法 `this(...)`。`super` 表示父类对象部分，可以访问父类成员、调用父类被重写的方法、在子类构造方法中调用父类构造方法 `super(...)`。`this(...)` 和 `super(...)` 都必须放在构造方法第一行，因此不能同时出现。

**记忆版：** `this` 找自己，`super` 找父类；构造里二选一，且必须第一行。

## 24. 构造方法能不能重写？为什么？

**通俗理解：** 不能。重写要求子类方法和父类方法同名同参数，但构造方法的名字必须和类名一样，父类和子类类名不同，所以构造方法不可能被重写。

**专业回答：** 构造方法不能被重写。方法重写发生在父子类之间，要求方法名、参数列表等满足重写规则；而构造方法不是普通成员方法，方法名必须与当前类名一致，且构造方法不会被继承。子类创建对象时可以通过 `super(...)` 调用父类构造方法完成父类部分初始化，但这不是重写。

**记忆版：** 构造方法不继承，所以不能重写；只能通过 `super(...)` 调用父类构造。
