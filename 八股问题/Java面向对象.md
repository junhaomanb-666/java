# Java 面向对象

## 1. 面向对象的三大特性是什么？

**答案：** 封装、继承、多态。

## 2. 类和对象的区别？

**答案：** 类是对事物的抽象描述，是对象的模板；对象是类的具体实例，会占用内存。

## 3. 方法重载和重写的区别？

**答案：** 重载发生在同一个类中，方法名相同，参数列表不同；重写发生在父子类之间，子类重新定义父类方法，方法签名相同。

## 4. 什么是封装？为什么要封装？

**答案：** 封装是将属性私有化，并通过公共方法对外访问。目的是保护数据安全，提高代码可维护性。

## 5. 构造方法的特点？

**答案：** 构造方法名与类名相同，没有返回值，可以重载，创建对象时自动调用，每个对象创建时通常只调用一次对应构造方法。

## 6. this 关键字的作用？

**答案：** `this` 表示当前对象，可以区分成员变量和局部变量，也可以调用本类其他构造方法。

## 7. 一个 .java 文件可以有多个类吗？

**答案：** 可以有多个类，但最多只能有一个 `public` 类，并且 `public` 类名必须与文件名一致。

## 8. 抽象类和接口的区别？

**答案：** 抽象类可以有抽象方法和具体方法，只能单继承；接口主要定义规范，Java 8 后可以有默认方法和静态方法，一个类可以实现多个接口。

## 9. String、StringBuffer、StringBuilder 的区别？

**答案：** `String` 不可变，线程安全；`StringBuffer` 可变，线程安全，方法使用 `synchronized`；`StringBuilder` 可变，线程不安全，但效率通常最高。

## 10. 多态的实现前提？

**答案：** 继承、方法重写、父类引用指向子类对象。

## 11. 面向过程和面向对象有什么区别？

**通俗理解：** 面向过程更关注“先做什么、再做什么”，像写菜谱步骤；面向对象更关注“谁来做、谁有什么能力”，像安排不同角色协作。

**专业回答：** 面向过程以函数和执行流程为中心，适合逻辑简单、步骤明确的场景。面向对象以对象为中心，将数据和行为封装在对象中，通过封装、继承、多态提高代码复用性、扩展性和维护性。Java 是典型面向对象语言。

**记忆版：** 面向过程看步骤，面向对象看对象和职责。

## 12. 内部类的优点是什么？

**通俗理解：** 内部类就是把一个类放到另一个类里面。它适合表达“这个类只为外部类服务”的关系，让代码更集中，也能方便访问外部类成员。

**专业回答：** 内部类可以增强封装性，将只在外部类内部使用的逻辑隐藏起来；可以直接访问外部类的成员，包括私有成员；可以让代码结构更贴近业务关系；还可以在一些回调、事件监听、策略封装场景中让实现更简洁。

**记忆版：** 内部类优点：封装强、访问方便、结构清晰、适合回调。
