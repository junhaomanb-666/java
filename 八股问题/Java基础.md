# Java 基础

> 本文件用于记录 Java 基础语法、JVM 基础和容易混淆的小知识点。

## 1. `&` 和 `&&` 的区别？

**通俗理解：** `&&` 更“聪明”，前面已经能判断结果时，后面就不看了；`&` 更“死板”，两边都会算。

**专业回答：** `&&` 是逻辑与，具有短路特性：当左侧表达式为 `false` 时，整个表达式必然为 `false`，右侧表达式不会执行。`&` 既可以作为按位与运算符，也可以用于布尔逻辑与；当用于布尔表达式时，不具备短路特性，左右两边都会执行。

**示例：**

```java
int a = 1;
if (a > 2 && ++a > 1) {
}
// a 仍然是 1，因为右侧没有执行

if (a > 2 & ++a > 1) {
}
// a 变成 2，因为右侧执行了
```

**记忆版：** `&&` 会短路，`&` 不短路；`&` 还能做按位与。

## 2. 什么是字节码？采用字节码的最大好处是什么？

**通俗理解：** Java 源代码不会直接变成某个系统专用的机器码，而是先编译成 `.class` 字节码。只要不同平台上有 JVM，这份字节码就能运行。

**专业回答：** 字节码是 Java 源代码经过编译器编译后生成的中间指令格式，通常保存在 `.class` 文件中，由 JVM 解释执行或通过 JIT 编译成本地机器码执行。采用字节码的最大好处是跨平台，即“一次编译，到处运行”。此外，字节码也便于 JVM 做安全校验、运行时优化和动态加载。

**记忆版：** 字节码 = Java 和 JVM 之间的中间语言；最大好处是跨平台。
