# Java 基础

> 本文件用于记录 Java 基础语法、JVM 基础和容易混淆的小知识点。

## 1. `&` 和 `&&` 的区别？

**通俗理解：** `&&` 更“聪明”，前面已经能判断结果时，后面就不看了；`&` 更“死板”，两边都会算。

**专业回答：** `&&` 是逻辑与，具有短路特性：当左侧表达式为 `false` 时，整个表达式必然为 `false`，右侧表达式不会执行。`&` 既可以作为按位与运算符，也可以用于布尔逻辑与；当用于布尔表达式时，不具备短路特性，左右两边都会执行。

**示例：**

```java
int a = 1;
if (a > 2 && ++a > 1) {
}
// a 仍然是 1，因为右侧没有执行

if (a > 2 & ++a > 1) {
}
// a 变成 2，因为右侧执行了
```

**记忆版：** `&&` 会短路，`&` 不短路；`&` 还能做按位与。

## 2. 什么是字节码？采用字节码的最大好处是什么？

**通俗理解：** Java 源代码不会直接变成某个系统专用的机器码，而是先编译成 `.class` 字节码。只要不同平台上有 JVM，这份字节码就能运行。

**专业回答：** 字节码是 Java 源代码经过编译器编译后生成的中间指令格式，通常保存在 `.class` 文件中，由 JVM 解释执行或通过 JIT 编译成本地机器码执行。采用字节码的最大好处是跨平台，即“一次编译，到处运行”。此外，字节码也便于 JVM 做安全校验、运行时优化和动态加载。

**记忆版：** 字节码 = Java 和 JVM 之间的中间语言；最大好处是跨平台。

## 3. Java 有哪些数据类型？

**通俗理解：** Java 数据类型分两大类：基本类型直接存值，引用类型保存对象引用。

**专业回答：** Java 数据类型分为基本数据类型和引用数据类型。基本数据类型有 8 种：整数类型 `byte`、`short`、`int`、`long`；浮点类型 `float`、`double`；字符类型 `char`；布尔类型 `boolean`。引用数据类型包括类、接口、数组、枚举、注解等。基本类型变量保存具体值，引用类型变量保存对象引用。

**记忆版：** 基本类型 8 个：四整两浮一字符一布尔；其他基本都是引用类型。

## 4. final 有什么用？

**通俗理解：** `final` 表示“最终确定”。修饰变量，值不能再改；修饰方法，不能被子类重写；修饰类，不能被继承。

**专业回答：** `final` 可以修饰变量、方法和类。修饰基本类型变量时，变量赋值后不能再修改；修饰引用类型变量时，引用地址不能改变，但对象内部状态仍可能改变；修饰方法时，子类不能重写该方法；修饰类时，该类不能被继承，例如 `String`。`final` 常用于常量定义、保护核心方法逻辑、防止类被扩展。

**记忆版：** `final` 三用法：变量不可改，方法不可重写，类不可继承。

## 5. Java 访问修饰符有什么区别？

**通俗理解：** 访问修饰符就是控制“谁能访问”。`public` 最开放，`private` 最严格，中间还有默认和 `protected`。

**专业回答：** Java 访问修饰符包括 `public`、`protected`、默认访问权限和 `private`。`public` 在任何地方可访问；`protected` 在同包内可访问，跨包时子类可访问；默认访问权限不写修饰符，只能在同包内访问；`private` 只能在当前类内部访问。访问范围从大到小是：`public` > `protected` > 默认 > `private`。

**记忆版：** 访问范围：公开 `public`，同包加子类 `protected`，同包默认，自己 `private`。

## 6. Java 获取反射 Class 对象的三种方法是什么？

**通俗理解：** 反射前要先拿到类的“说明书” `Class` 对象，常见方式有：类名拿、对象拿、全类名字符串拿。

**专业回答：** 获取 `Class` 对象常见三种方式：第一，使用 `类名.class`，例如 `User.class`，适合编译期已知类；第二，使用对象的 `getClass()` 方法，例如 `user.getClass()`，适合已有对象实例；第三，使用 `Class.forName("全限定类名")`，例如 `Class.forName("com.demo.User")`，适合运行时根据字符串动态加载类。

**示例：**

```java
Class<?> c1 = User.class;
Class<?> c2 = user.getClass();
Class<?> c3 = Class.forName("com.demo.User");
```

**记忆版：** 反射拿 `Class`：类名 `.class`、对象 `.getClass()`、字符串 `Class.forName()`。
