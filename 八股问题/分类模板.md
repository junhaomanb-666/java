# 八股问题分类模板

复制下面的模板即可新增一道八股题。

```text
## 题号 标题

**类别：**

**标签：**

**题目：**

**答案：**

**解析：**

**考点：**

- 

**易错点：**

- 

**复习动作：**

- 
```

## 分类文件命名建议

后续按内容自动创建，例如：

- `Java基础.md`
- `Java集合.md`
- `Java并发.md`
- `JVM.md`
- `MySQL.md`
- `Redis.md`
- `Spring.md`
- `计算机网络.md`
- `操作系统.md`
- `数据结构与算法.md`
- `项目场景题.md`
